## 情报筛选原则

1. 优先使用论文、官方博客、产品文档和官方 GitHub 仓库。
2. 标注发布时间、版本状态和核验日期。
3. 不把 Star、点赞或榜单排名当作项目质量证明。
4. 解释实际用途、适用人群、限制和上手入口。
5. 对未能确认的信息明确标注，不把猜测写成事实。

## 单条情报模板

- 日期 / 来源
- 项目或技术是什么（白话解释）
- 核心原理与解决的问题
- 典型应用场景

- 官方入口 / 论文 / GitHub
- 学习或实践建议
